# Hands-On Machine Learning

My personal learning repository based on **Hands-On Machine Learning with Scikit-Learn and PyTorch** by Aurélien Géron.

This repository contains my solutions to chapter exercises, code implementations, experiments, and notes created while studying Machine Learning and Deep Learning.

The main goal is to strengthen my understanding of ML/DL concepts through hands-on practice and experimentation.

## 📚 Book

**Hands-On Machine Learning with Scikit-Learn and PyTorch**

Author: Aurélien Géron

## 📂 Repository Structure

Each chapter has its own directory containing exercises, implementations, and additional experiments.
